# Escape the Radical Manor

A Halloween-themed Intermediate Algebra practice game: students solve quadratic equations by taking square roots, with every answer fully simplified and the denominator rationalized. Solve five locks to collect five treasures and escape the manor.

- Rooms cover `ax² = b`, `ax² + k = c`, `a(x − h)² = b`, `a(x − h)² + k = c`, and imaginary solutions.
- The ghost gives step-by-step hints, the Spellbook explains rationalizing, and the Pumpkin Patch is ungraded extra practice.
- When students escape, they get an escape code tied to their name. Use the **Teacher** link at the bottom of the page to verify it.

## Running it

Open `index.html` in any modern browser. It's a single self-contained file; progress is saved in the browser's local storage.

To host it with GitHub Pages: Settings → Pages → deploy from the `main` branch, root folder.
